    Election checklist

    1. Approve members on the Members tab
    2. Add candidates on the Candidates tab (before creating an election)
    3. Create an election on the Elections tab — it saves a copy of the current candidates at that moment
    4. Set election status to Open when voting should begin
    5. Admins vote on the Vote tab — once per election
    6. Set status to Closed when voting ends
    7. If any positions are tied, click Start runoff on the Results tab
    8. Close the runoff when voting ends, then Publish results
